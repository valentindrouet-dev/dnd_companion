# sources/ — fichiers de travail pour l'ingestion

Ce dossier reçoit les PDF (aventures, Monster Manual, etc.) et les textes extraits.
Il est **ignoré par git** (`sources/pdf/` et `sources/txt/`) : le dépôt étant public,
aucun contenu sous copyright ne doit y être poussé. Seules les fiches JSON que l'on
rédige nous-mêmes dans `data/` sont versionnées.

Voir `docs/INGESTION.md` pour le déroulé complet.
